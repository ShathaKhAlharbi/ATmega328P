# ATmega328P Bare-Metal Projects

A progressive collection of Embedded C projects for the ATmega328P
microcontroller, organized from fundamental GPIO concepts to
interrupt-driven systems and an integrated temperature controller.

## Concepts Covered

- GPIO configuration
- Digital input/output
- Bit manipulation
- LED control
- LCD interfacing
- 4-bit and 8-bit communication
- ADC
- Sensor interfacing
- Timers
- Interrupts
- Embedded C
- ATmega328P bare-metal programming
  
## Development

The projects are written in Embedded C and target the ATmega328P
microcontroller.
