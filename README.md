# ATmega328P Bare-Metal Projects

A progressive collection of Embedded C projects for the ATmega328P
microcontroller, organized from fundamental GPIO concepts to
interrupt-driven systems and an integrated temperature controller.

## Learning Path

The projects are arranged by increasing difficulty:

### 1. GPIO Fundamentals
- [01 — GPIO LED Blink](./01-GPIO-LED-Blink)
- [02 — Running LEDs](./02-GPIO-Running-LEDs)
- [03 — GPIO Input/Output](./03-GPIO-Input-Output)

### 2. LCD Interfacing
- [04 — LCD 8-bit Initialization](./04-LCD-8Bit-Initialization)
- [05 — LCD 4-bit State Control](./05-LCD-4Bit-State-Control)
- [06 — LCD 8-bit Parallel Interface](./06-LCD-8Bit-Parallel-Interface)

### 3. ADC and Sensor Integration
- [07 — ADC Polling](./07-ADC-Polling)
- [08 — Sensor Input & LCD Counter](./08-Sensor-Input-LCD-Counter)

### 4. Timers and Data Display
- [09 — Timer Square Wave Generator](./09-Timer-Square-Wave-Generator)
- [10 — LCD Telemetry Display](./10-LCD-Telemetry-Display)

### 5. Interrupt-Driven Systems
- [11 — ADC Interrupt-Driven Monitor](./11-ADC-Interrupt-Driven-Monitor)

### 6. Integrated Project
- [12 — Temperature Control System](./12-Temperature-Control-System)

## Concepts Covered

- GPIO configuration
- Digital input/output
- Bit manipulation
- LED control
- LCD interfacing
- 4-bit and 8-bit communication
- ADC
- Sensor interfacing
- Timers
- Interrupts
- Embedded C
- ATmega328P bare-metal programming

## Hardware

- ATmega328P
- LEDs
- Push buttons
- LCD
- Potentiometer / analog input
- Temperature sensor

## Development

The projects are written in Embedded C and target the ATmega328P
microcontroller.
